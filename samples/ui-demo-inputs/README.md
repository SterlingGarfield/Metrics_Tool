# UI Demo Inputs

These sample files are prepared for the four input modes in the web UI.

## Code Input

Open `samples/ui-demo-inputs/code-input/CodeInputSample.java` and paste its content into the `Code Input` textarea.

## Single File

Upload `samples/ui-demo-inputs/single-file/SingleFileDemo.java`.

## Multiple Files

Upload all `.java` files under `samples/ui-demo-inputs/multiple-files/`.

## Folder Scan

Choose the folder `samples/ui-demo-inputs/folder-scan/` in the `Folder Scan` mode.
